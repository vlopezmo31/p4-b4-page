# Dopatask - Projecte Universitari

## Introducció

**Dopatask** és una aplicació web desenvolupada com a projecte universitari per a l’assignatura Factors Humans i Computació a la Universitat de Barcelona. El seu objectiu és oferir una eina senzilla i eficaç per a la gestió de tasques, pensada per a estudiants i equips acadèmics que necessiten organitzar activitats, terminis i col·laboracions de manera eficient. La pàgina web del projecte està allotjada a GitHub Pages i es pot visitar aquí: **[Dopatask](https://vlopezmo31.github.io/p4-b4-page/)**. A més, pots veure una demostració en viu de l’aplicació al següent enllaç: **[Demo Live](https://youtu.be/inyi73MARiE)**.

Aquest projecte busca demostrar habilitats en desenvolupament web, treball en equip i resolució de problemes pràctics, alineant-se amb els objectius acadèmics de l’assignatura. Dopatask combina una interfície amigable amb funcionalitats bàsiques de gestió de tasques, servint com a prototip funcional per a possibles implementacions futures.

## Objectius del Projecte

- Desenvolupar una aplicació web funcional utilitzant tecnologies modernes.
- Implementar un sistema de gestió de tasques amb una interfície intuïtiva.
- Aplicar concept |es de disseny web responsiu i accessibilitat.
- Demostrar col·laboració en equip mitjançant l’ús de control de versions (Git/GitHub).

## Funcionalitats

- **Creació i Gestió de Tasques**: Permet afegir, editar i eliminar tasques amb detalls com títol, descripció i data límit.
- **Visualització de Tasques**: Mostra les tasques en una llista.
- **Creació i Gestió d'Habits**: Permet afegir, editar i eliminar tasques amb detalls com títol.
- **Visualització d'Habits**: Mostra els habits en una llista.
- **Sistema de Recompenses Avançat**: Incorpora un sistema de recompenses per motivar a l¡usuari.
- **Disseny Responsiu**: Interfície adaptada per a dispositius mòbils i d’escriptori.
- **Pàgina Pública**: La web a GitHub Pages presenta el projecte, amb informació sobre les seves característiques i captures de pantalla.

## Estructura del Projecte

El projecte està organitzat en les següents parts:

1. **Frontend**:
   - Desenvolupat amb HTML, CSS .
   - Utilitza Bootstrap per a un disseny responsiu i consistent.
   - Arxius ubicats a la carpeta `/src`.
   - Inclou una interfície neta amb un enfocament en l’usabilitat per a estudiants.

2. **Backend**:
   - Desenvolupat amb Javascript
   - Arxius ubicats a la carpeta `/src/js`.

3. **GitHub Pages**:
   - La pàgina estàtica desplegada a **[https://vlopezmo31.github.io/p4-b4-page/](https://vlopezmo31.github.io/p4-b4-page/)** actua com a presentació oficial del projecte.

## Tecnologies Utilitzades

- **HTML5**: Estructura de la interfície.
- **CSS3**: Estils visuals, amb suport de Bootstrap.
- **JavaScript**: Lògica interactiva per a la gestió de tasques.

## Conclusió

**Dopatask** és un prototip funcional que compleix amb els objectius acadèmics establerts, demostrant l’ús de tecnologies web per resoldre un problema quotidià com la gestió de tasques. La pàgina a GitHub Pages ofereix una visió clara del projecte, mentre que el codi reflecteix l’esforç de l’equip en crear una solució pràctica i ben dissenyada.

Aquest projecte ha estat desenvolupat per Víctor López, Èlia Garcia, Mario Esteban, Anna Haro i Helena Amérigo com a part d’un treball acadèmic.
